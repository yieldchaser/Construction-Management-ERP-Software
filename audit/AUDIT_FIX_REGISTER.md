## Why waves, not one big batch

Prompts cite `file:line`. A fix shifts every later line in that file, so a prompt written before
the fix is stale. Findings are therefore grouped by the file they primarily touch: **write, verify,
fix and re-verify one wave, commit, regenerate, then start the next.**
